# mcgl-online-check

Отправляет сообщение в Discord по вебхуку, когда пользователи [forum.minecraft-galaxy.ru](https://forum.minecraft-galaxy.ru) заходят в сеть или выходят из неё.

## Настройка

Настройки берутся из переменных окружения

| Переменная        | Обязательна | Описание                                                  |
| ----------------- | ----------- | --------------------------------------------------------- |
| `POSTS`           | да          | Ссылки на посты отслеживаемых пользователей через запятую |
| `DISCORD_WEBHOOK` | нет         | Вебхук Discord                                            |
| `INTERVAL_SEC`    | нет         | Интервал проверки в секундах, по умолчанию 60             |
